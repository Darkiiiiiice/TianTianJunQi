> 状态：**占位骨架**。本文件是 `trainer/src/wgai/sim/` 规则引擎的唯一规则来源，
> `rules.json` 版本与之绑定。规则未确认前不得开始 M2-2（规则实现）。
> 责任任务：开发计划 P0-5（规则确认）→ M2-2（规则实现）→ M2-6（回放回归）。

## 1. 版本

- rulesVersion：`fanfanqi-0`（占位；P0-5 确认后定为 `fanfanqi-1`）
- 规则改动必须升级版本号；旧模型与数据集随之标记不兼容（stale）。

## 2. 棋盘

- [ ] rows × cols：公开资料常见 4×8，待 P0-3 实测确认，禁止硬编码
- [ ] 格子布局、是否有特殊格

## 3. 棋子集合与军衔

- [ ] 双方各多少枚、棋子集合是否对称
- [ ] 军衔从高到低顺序（待 P0-5）
- [ ] 特殊棋子规则：炸弹 / 地雷 / 军旗

## 4. 行动规则

- [ ] 翻牌：点暗子翻开；翻出颜色是否决定己方阵营（待确认）
- [ ] 移动：是否限相邻一格；有无特殊棋子扩展移动
- [ ] 吃子判定：高吃低、同级互灭、炸弹/地雷/军旗交互
- [ ] 连续行动：吃子/翻牌后是否继续行动（待确认）

## 5. 胜负条件

- [ ] 吃光对方可移动棋子
- [ ] 扛走军旗
- [ ] 超时判负/判和规则

- 与游戏实际行为不一致数为 0 才允许进入 M3 训练。
